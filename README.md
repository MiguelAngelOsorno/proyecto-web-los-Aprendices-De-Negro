## El cliente
Es un negocio tradicional de abarrotes ubicado en el barrio (Granero El Relajo). Vende una amplia variedad de productos de la canasta familiar, granos, víveres, lácteos, bebidas y artículos de aseo para el hogar. Necesita de su página web para tener presencia digital, mostrar su catálogo de productos con precios actualizados y facilitar un canal de contacto directo con los vecinos del sector.

## El público
Los vecinos del barrio, familias y compradores locales que buscan adquirir productos de primera necesidad de forma rápida, consultar precios desde casa y conocer la ubicación o métodos de contacto del granero sin necesidad de trasladarse inicialmente.
